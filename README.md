# annietsai.github.io

Personal website built with React, TypeScript, and Vite.

## 🚀 Getting Started

### Local Development
To run the project locally for testing:
```bash
npm run build
npm run preview
```

### Deployment
To deploy the latest changes to GitHub Pages:
```bash
git checkout master
git pull origin master
npm run deploy
```

## 🛠️ Tech Stack
- **Frontend:** React + TypeScript
- **Build Tool:** Vite
